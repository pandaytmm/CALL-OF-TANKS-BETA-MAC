# Tank Savaşı Android Projesi

- `main.py`: Android dokunmatik kontrolleri eklenmiş oyun kodu.
- `tank_oyunu_original.py`: yüklenen orijinal Python oyununun kopyası.
- `buildozer.spec`: Android paketleme ayarları (Python 3.11.9 sürümüyle sabitlenmiş).
- `.github/workflows/build-android.yml`: GitHub Actions üzerinden APK derleme iş akışı.
- `ANDROID_KURULUM.md`: Türkçe kurulum ve derleme rehberi.

Bu kaynak pakettir, önceden derlenmiş APK değildir. Google Colab ile kolay derleme için ayrıca `TankSavasi_Android_APK_Yapici.ipynb` dosyasını kullan.
